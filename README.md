# The ESKAPE Phage Repository
**A collection of Bacteriophages targeting ESKAPE Pathogens**

The ESKAPE pathogens: *Enterococcus faecium*, *Staphylococcus aureus*, *Klebsiella pneumoniae*, *Acinetobacter baumannii*, *Pseudomonas aeruginosa*, and *Enterobacter* species are key pathogenic bacteria contributing towards the global Antibiotic Resistance crisis. 
This repository hosts a curated collection of diverse bacteriophage morphology data, generated through the Transmission Electron Microscopy.

## Project Overview
The primary goal of this repository is to provide an accessible web interface for browsing high-resolution Transmission Electron Microscopy (TEM) micrographs of bacteriophages and their detailed structural morphology. 

## Future Development
In future detailed genomic characterization data will be incorporated for selected bacteriophages.
